# New Al Khan Engineering Works

Premium website for New Al Khan Engineering Works — cosmetic and pharmaceutical machinery manufacturer.

## Tech Stack

- React 19
- Vite 6
- Tailwind CSS 4
- React Router 7

## Getting Started

### Prerequisites

- Node.js 18+ installed

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open the URL shown in the terminal (typically `http://localhost:5173`).

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Project Structure

```
src/
├── components/      # Reusable UI and layout components
├── sections/        # Page sections (Hero, CEO, About, etc.)
├── pages/           # Route pages
├── hooks/           # Custom React hooks
├── data/            # Company, products, blog data
├── utils/           # Utility functions
├── styles/          # Global styles and Tailwind
├── App.jsx
└── main.jsx
```
